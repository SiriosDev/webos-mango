# webOS Mango 🥭 [^1]

Personal repo for [webOS Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) and [LG Dev Manager](https://github.com/Scoty/lg-dev-manager)

Intended for personal use, this list includes all apps that are currently unavailable or will not be accepted into the official repository.

## Functional Disclaimer
As well as those that may be added or removed without notice. If (for some strange and masochistic reason) you want to use it, please keep this in mind.
So, use the official repository or, if necessary, the `repo.json` files provided by the developers of the respective apps (or create your own `repo.json` file)
